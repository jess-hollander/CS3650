# Assignment 5: Basic Memory Allocator

This is the starter code for [Assignment 5]

The [Makefile](Makefile) contains the following targets:

- `make all` - compile [mymalloc.c](mymalloc.c) (and any other top-level `.c` files) into object files
- `make test` - compile and run tests in the [tests](tests/) directory with `mymalloc.o`.
- `make test-quiet` - same as `make test`, with `debug_printf` output turned off
- `make demo` - compile and run tests in the tests directory with standard malloc.
- `make clean` - perform a minimal clean-up of the source tree
- `make help` - print available targets
